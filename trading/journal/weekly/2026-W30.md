## Lesson

Session 1 (interactive) was blocked by `TRADER_DRY_RUN=1` in the shell
profile; Session 2 the same afternoon ran without that guard and submitted
live cleanly. Lesson: the dry-run guard is per-environment, not per-account
— always verify the order path with one small test order before assuming
either mode, and journal which mode the session actually ran in.
